# Заливка области

Автоматическая расстановка блоков, текста или мультитекста внутри заданного контура.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_FILL_AREA — расстановка блоков и текста внутри контура

Заполняет замкнутый контур образцами по регулярной сетке. Удобно для штриховки условными знаками, отметками высот и т.п.

### Шаг 1. Контур

Укажите границу заливки одним из двух способов в диалоговом окне:

- **Выбор контура** — кнопка **«Выбрать»**: выделите на чертеже полилинию, кривую или сплайн;
- **Определение контура** — кнопка **«Определить»**: нарисуйте замкнутый контур последовательным указанием точек (Enter или ПКМ — завершить).

### Шаг 2. Образец

Кнопка **«Выбрать на чертеже»** — укажите блок, текст или мультитекст, которым будет заполняться область.

### Шаг 3. Параметры расстановки

- **Интервал (шаг по X и Y)** — расстояние между соседними экземплярами.
- **Порядок расстановки**:
  - *Шахматный* — ряды со сдвигом на половину шага;
  - *Сетка* — ровные ряды по сетке;
  - *Случайный* — со случайным смещением; разброс настраивается ползунком **«Разброс»** (0–100 %).

### Шаг 4. Запуск

Нажмите **OK**. Плагин расставит образцы внутри контура, автоматически отступая от границы на половину размера образца. Итоговое количество объектов появится в командной строке.

::: tip Совет
Все параметры запоминаются: шаг, режим расстановки и выбранный блок подставляются при следующем запуске.
:::

::: info Информация
Динамические (анонимные) блоки используются для текущего запуска, но не сохраняются для автозагрузки — при повторном открытии их придётся выбрать заново.
:::
