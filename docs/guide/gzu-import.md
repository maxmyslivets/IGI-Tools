# Импорт ГЗУ

Импорт границ землепользования (ГЗУ) из файлов GeoJSON.

---

## <img src="/icons/IGI_GZU_FROM_GEOJSON.svg" style="height:24px; vertical-align:middle"> IGI_GZU_FROM_GEOJSON — импорт ГЗУ из GeoJSON

Импортирует границы землепользования из GeoJSON в текущий чертёж. Поддерживает стандартный GeoJSON (Feature, FeatureCollection, Polygon, MultiPolygon) и формат портала gismap.by.

1. Введите `IGI_GZU_FROM_GEOJSON`, нажмите Enter.
2. В открывшемся диалоге выберите файл `.json` / `.geojson`.
3. Плагин создаст:
   - замкнутые полилинии по внешним контурам и внутренним вырезам (цвет — зелёный, слой «0»);
   - блоки **СП_1.5** в каждой вершине каждого кольца (масштаб 0,5, цвет — зелёный).
4. В консоли появится статистика: количество полигонов, дыр, вершин и вставленных блоков.

::: info Информация
Блок **СП_1.5** берётся из файла шаблона `template.dwg`. Если в шаблоне блока нет — импорт остановится с понятным сообщением.
:::

::: warning Внимание
Координаты в GeoJSON должны быть в той же системе координат, что и текущий чертёж. Плагин не выполняет пересчёт между системами координат.
:::
