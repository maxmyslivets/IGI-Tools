# Настройки плагина

На этой странице описаны команды, отвечающие за обслуживание плагина: проверка обновлений, управление шаблоном чертежа и подключение цифровых моделей рельефа (ЦМР).

---

## Проверка обновлений

### IGI_CHECK_UPDATE — ручная проверка

Команда проверяет на GitHub, вышла ли новая версия IGI Tools.

1. В командной строке AutoCAD (или Civil 3D) введите `IGI_CHECK_UPDATE` и нажмите Enter.
2. Плагин отправит запрос к GitHub и покажет результат:

   - **Актуальная версия** — появится окно с сообщением: «Установлена актуальная версия IGI Tools».
   - **Доступно обновление** — появится окно с информацией:
     - установленная версия;
     - актуальная версия;
     - размер установщика;
     - список изменений (что нового).
   - Если обновление доступно, нажмите **Да** — откроется страница скачивания установщика в браузере.
   - Нажмите **Нет**, чтобы отложить обновление до следующего сеанса.

::: warning Внимание
Перед запуском скачанного установщика обязательно закройте AutoCAD / Civil 3D. Запускайте установщик от имени администратора.
:::

### IGI_CHECK_UPDATE — автопроверка при старте

Плагин автоматически проверяет наличие обновлений при каждом запуске AutoCAD / Civil 3D (с задержкой ~2,5 секунды после загрузки). Если установлена актуальная версия, диалог не показывается. Если доступно обновление — появится то же окно, что и при ручной проверке.

::: tip Совет
Чтобы не пропускать новые версии, достаточно просто следить за сообщением в консоли AutoCAD при старте. Если версия актуальна, плагин пишет: `[IGI Tools] Версия актуальна (X.X.X)`.
:::

## Управление шаблоном

Плагин использует файл `template.dwg`, который содержит служебные блоки, слои и типы линий. Вы можете заменить его на свой или вернуть заводской.

### IGI_LOAD_TEMPLATE — загрузить пользовательский шаблон

Позволяет указать свой DWG-файл в качестве шаблона.

1. В командной строке AutoCAD введите `IGI_LOAD_TEMPLATE` и нажмите Enter.
2. Откроется стандартный диалог выбора файла — укажите нужный DWG.
3. Плагин скопирует выбранный файл в папку ресурсов как `template.dwg`.
4. Если файл уже был заменён ранее, старый шаблон автоматически сохранится с расширением `.bak`.

::: info Информация
Выбранный DWG будет скопирован внутрь установки плагина. Исходный файл остаётся нетронутым — плагин работает с копией.
:::

### IGI_RESET_TEMPLATE — сбросить шаблон к заводскому

Восстанавливает исходный `template.dwg`, который поставлялся с установщиком.

1. В командной строке AutoCAD введите `IGI_RESET_TEMPLATE` и нажмите Enter.
2. Плагин скопирует заводской шаблон из дистрибутива, заменяя текущий пользовательский.

::: tip Совет
Если после загрузки собственного шаблона что-то пошло не так — выполните `IGI_RESET_TEMPLATE`, чтобы вернуть исходное состояние.
:::

## Управление ЦМР

### <img src="/icons/IGI_Tools.svg" style="height:24px; vertical-align:middle"> IGI_DEM_MANAGER — окно «Менеджер ЦМР»

Подключает GeoTIFF-файлы цифровой модели рельефа и управляет ими. Плагин поддерживает одновременную работу с несколькими ЦМР.

1. Введите `IGI_DEM_MANAGER`, нажмите Enter.
2. Нажмите **Добавить ЦМР…**.
3. Выберите один или несколько GeoTIFF-файлов `*.tif;*.tiff` и нажмите **Открыть**.
4. Подключённые растры появятся списком. Флажок у растра означает, что он используется для определения высот.

Окно позволяет:

- включать и выключать каждый растр флажком;
- выгружать один растр кнопкой **Выгрузить**;
- выгрузить все растры кнопкой **Выгрузить все** (с запросом подтверждения);
- закрыть окно кнопкой **Закрыть**.

::: tip Совет
Последний использованный GeoTIFF запоминается в настройках и загружается автоматически при следующем запуске команды `IGI_DEM_TRACKER`.
:::

::: warning Внимание
GeoTIFF должен быть корректно привязан к системе координат чертежа. Обычный TIFF без геопривязки не подойдёт — плагин выдаст сообщение об ошибке.
:::
