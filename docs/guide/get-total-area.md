# Суммарная площадь вложенных полигонов

Вычисление суммарной площади группы вложенных замкнутых полилиний с автоматическим учётом отверстий (дыр).

---

## ![Icon](/icons/IGI_GetTotalAreaOfNestedPolygons.svg){style="height:24px; vertical-align:middle"} IGI_GETTOTALAREAOFNESTEDPOLYGONS — площадь с учётом вложенности

Анализирует выбранные замкнутые полилинии, строит дерево вложенности и вычисляет итоговую площадь: внешние контуры суммируются, а внутренние отверстия (дыры) вычитаются.

1. Введите `IGI_GETTOTALAREAOFNESTEDPOLYGONS`, нажмите Enter.
2. Если на чертеже есть предварительно выбранные объекты, команда автоматически использует их.
3. Если предварительного выбора нет, появится запрос: выберите замкнутые полилинии и нажмите Enter.
4. Команда проанализирует геометрию и построит дерево вложенности: внешний контур → отверстие → внутренний контур и т.д.
5. Результат выводится в командную строку:
   ```
   [IGI Tools] 12345.67 м2 ( 1.23 га )
   [IGI Tools] Обработано полигонов: 12, внешних контуров: 7.
   ```

::: tip Совет
Для быстрого выбора удобно сначала выделить все нужные полилинии рамкой, а затем ввести команду `IGI_GETTOTALAREAOFNESTEDPOLYGONS` — предварительный выбор подхватится автоматически.
:::

::: info Информация
- Учитываются только **замкнутые** полилинии (LWPOLYLINE). Незамкнутые пропускаются с предупреждением.
- Вложенность определяется через Shapely: если один полигон полностью покрывает другой, внешний считается контуром, а внутренний — отверстием.
- Полилинии с самопересечениями и менее чем 3 вершинами пропускаются.
- Уровень вложенности не ограничен — алгоритм корректно обрабатывает многоуровневую вложенность (контур → дыра → остров → дыра).
:::

::: warning Внимание
Полилинии не должны пересекать друг друга частично — только отношение полного покрытия (один внутри другого). Частично перекрывающиеся полигоны приведут к некорректному результату.
:::
