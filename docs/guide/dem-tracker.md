# DEM-трекер

Отслеживание высоты поверхности (Z) из цифровой модели рельефа (GeoTIFF) под курсором в реальном времени.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_DEM_TRACKER — высота поверхности под курсором

Показывает Z-высоту из файла GeoTIFF рядом с курсором. Значение обновляется при движении мыши.

1. Введите `IGI_DEM_TRACKER`, нажмите Enter.
2. При первом запуске — выберите GeoTIFF-файл через команду `IGI_DEM_TRACKER_SELECT_FILE`. При повторном — подхватится последний использованный файл.
3. Рядом с курсором появится полупрозрачная плашка **«Z: … м»**.
4. Повторный `IGI_DEM_TRACKER` останавливает мониторинг, плашка исчезает.

### Дополнительные команды

- `IGI_DEM_TRACKER_SELECT_FILE` — выбрать другой DEM-файл без остановки мониторинга.
- `IGI_DEM_TRACKER_STOP` — принудительно остановить мониторинг и скрыть плашку.

::: tip Совет
Последний использованный DEM-файл запоминается в настройках и загружается автоматически при следующем запуске.
:::

::: warning Внимание
GeoTIFF должен быть корректно привязан к системе координат чертежа. Обычный TIFF без геопривязки не подойдёт — плагин выдаст сообщение об ошибке.
:::
