# DEM-трекер

Отслеживание высоты поверхности (Z) из цифровой модели рельефа (GeoTIFF) под курсором в реальном времени.

---

## <img src="/icons/IGI_Tools.svg" style="height:24px; vertical-align:middle"> IGI_DEM_TRACKER — высота поверхности под курсором

Показывает Z-высоту из активной ЦМР рядом с курсором. Значение обновляется при движении мыши.

1. Введите `IGI_DEM_TRACKER`, нажмите Enter.
2. Рядом с курсором появится полупрозрачная плашка **«Z: … м»**, следующая за мышью.
3. Повторный `IGI_DEM_TRACKER` останавливает мониторинг, плашка исчезает.

Поведение при запуске:

- если ЦМР уже подключены — отслеживание начинается сразу, без запроса;
- иначе плагин автоматически загружает последний использованный GeoTIFF из настроек;
- если файла нет — откроется диалог выбора GeoTIFF.

::: tip Совет
При нескольких подключённых ЦМР высота берётся из первой активной модели в порядке подключения.
:::

---

## <img src="/icons/IGI_Tools.svg" style="height:24px; vertical-align:middle"> IGI_DEM_TRACKER_STOP — остановить мониторинг

Останавливает отслеживание и закрывает плашку с высотой.

1. Введите `IGI_DEM_TRACKER_STOP`, нажмите Enter.

::: info Информация
Остановка трекера не выгружает ЦМР — она остаётся подключённой и доступна другим инструментам, например [отметкам из ЦМР](/guide/elev-marks).
:::
