# Блоки и точки

Утилиты для создания, поиска и преобразования блоков и точек на чертеже.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_z2sp92 — создание блоков СП_9.2 из объектов с высотой

Вставляет блок **СП_9.2** в каждую точку выделенных объектов, перенося значение Z из координаты объекта в атрибут блока.

1. Введите `z2sp92`, нажмите Enter.
2. Выделите любые объекты с координатой Z (точки, блоки, текст).
3. Плагин вставит блоки **СП_9.2** (масштаб 0,5, цвет — по слою).
4. Подтвердите удаление исходных объектов при необходимости.

::: info Информация
Если блок **СП_9.2** отсутствует в чертеже, команда прервётся с сообщением об ошибке. Убедитесь, что блок загружен через шаблон или создан заранее.
:::

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_z2sp652 — парная расстановка блоков СП_6.5.2

Находит пары объектов, расположенные близко по плановым координатам (в пределах допуска), и вставляет блок **СП_6.5.2** с атрибутами **H** (высота верхнего) и **Z** (отметка нижнего).

1. Введите `z2sp652`, нажмите Enter.
2. При необходимости измените допуск расстояния.
3. Выделите объекты для поиска пар.
4. Плагин проанализирует объекты и создаст блоки со сводными отметками.
5. Подтвердите удаление исходных.

::: tip Совет
Значение допуска запоминается на весь сеанс AutoCAD. Типовое значение — 20–30 см для парных точек тахеометрической съёмки.
:::

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_SP92ToPoints — экспорт блоков СП_9.2 в точки

Преобразует блоки **СП_9.2** в примитивы **Point** на координатах X, Y блока с высотой Z из атрибута.

1. Введите `SP92ToPoints`, нажмите Enter.
2. Выделите блоки **СП_9.2**.
3. На месте каждого блока появится точка с отметкой Z.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_SelectSP92 — поиск и подсветка блоков СП_9.2

Находит все блоки **СП_9.2** на чертеже (включая динамические анонимные) и подсвечивает их.

1. Введите `SelectSP92`, нажмите Enter.
2. Если до запуска были выделены объекты — поиск среди них. Если нет — укажите область или нажмите Enter для поиска по всему чертежу.
3. Найденные блоки подсветятся, в консоли — их количество.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> BlockToVertex — копирование блока по вершинам полилинии

Копирует выбранный блок во все вершины указанной полилинии.

1. Введите `block2vertex`, нажмите Enter.
2. Укажите полилинию, затем блок-образец.
3. Копии блока расставляются во все вершины с сохранением слоя.

---

## <img src="/icons/IGI_BlockFan.svg" style="height:24px; vertical-align:middle"> IGI_BlockFan — веер блоков

Создаёт указанное количество повёрнутых копий блоков с шагом 15° вокруг базовой точки.

1. Введите `BlockFan`, нажмите Enter.
2. Выберите один или несколько блоков.
3. Введите общее количество элементов в веере (включая исходный, например, 5 — будет 4 копии с поворотом 15°, 30°, 45°, 60°).
