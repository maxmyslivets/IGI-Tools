# Высоты и Z-координаты

Утилиты для работы с высотными отметками: обнуление, корректировка, перенос между атрибутами и координатами.

---

## <img src="/icons/igi_z0.svg" style="height:24px; vertical-align:middle"> IGI_Z0 — обнуление всех объектов на Z=0

Переносит все объекты чертежа на плоскость Z=0. Выполняет аудит, сбор всей геометрии и математическое обнуление.

1. Введите `IGI_Z0`, нажмите Enter.
2. Плагин выполнит три шага:
   - проверку чертежа (аналог _AUDIT);
   - сбор всей геометрии;
   - проецирование всех объектов на Z=0.
3. В консоли — итоговое количество обработанных объектов.

::: warning Внимание
Команда обрабатывает **все** объекты чертежа. Перед запуском убедитесь, что вы не потеряете нужные 3D-данные.
:::

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_FIX_Z_SP92 — корректировка атрибута Z в блоках СП_9.2

Массово изменяет значение атрибута **Z** в выбранных блоках **СП_9.2** на заданную поправку.

1. Введите `IGI_FIX_Z_SP92`, нажмите Enter.
2. Выберите режим ввода поправки:
   - **1** — ввести величину dZ вручную (например, `-0.15` или `0.20`);
   - **2** — рассчитать поправку по высоте вехи (введите фактическую и заданную высоту, плагин вычислит dZ = H<sub>зад</sub> − H<sub>факт</sub>).
3. Выделите блоки **СП_9.2**, которые нужно изменить.
4. Скорректированные блоки подсветятся.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_FIX_Z_FROM_ATTR_SP92 — перенос Z из атрибута в координату блока

Переносит значение атрибута **Z** блока **СП_9.2** в его физическую координату Z (точку вставки).

1. Введите `IGI_FIX_Z_FROM_ATTR_SP92`, нажмите Enter.
2. Выделите блоки **СП_9.2**.
3. Плагин переместит каждый блок на высоту, указанную в его атрибуте Z.
