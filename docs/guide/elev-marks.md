# Отметки из ЦМР

Автоматическая вставка блоков **СП_9.2** с отметкой высоты Z, снятой с цифровой модели рельефа (GeoTIFF) в точке вставки.

Перед работой подключите ЦМР командой `IGI_DEM_MANAGER`. Точки, в которых у ЦМР нет данных, пропускаются.

---

## ![Иконка](/icons/IGI_ELEV_MARK.svg) IGI_ELEV_MARK — отметки по кликам

Вставляет блок **СП_9.2** с высотой из ЦМР в указанную точку.

1. Введите `IGI_ELEV_MARK`, нажмите Enter.
2. Кликайте по чертежу — в каждой точке появится блок с отметкой Z.
3. Чтобы удалить последнюю отметку, нажмите **Ctrl+Z** или введите ключевое слово **Отмена**.
4. Для выхода нажмите **Esc**.

---

## ![Иконка](/icons/IGI_ELEV_MARK_LINES.svg) IGI_ELEV_MARK_LINES — отметки вдоль линий

Расставляет отметки вдоль выбранных отрезков и полилиний с заданным шагом.

1. Введите `IGI_ELEV_MARK_LINES`, нажмите Enter.
2. В окне параметров укажите **максимальное расстояние между точками (м)** и нажмите **Выполнить**.
3. Выделите линии и полилинии. Если нужные объекты выбраны заранее (предвыбор), они используются автоматически.
4. Плагин расставит отметки вдоль объектов; дуговые сегменты полилиний разбиваются автоматически.

В конце команда выводит число нанесённых и пропущенных отметок.

---

## ![Иконка](/icons/IGI_ELEV_MARK_GRID.svg) IGI_ELEV_MARK_GRID — отметки по сетке в границе

Расставляет отметки по регулярной сетке внутри замкнутой полилинии.

1. Введите `IGI_ELEV_MARK_GRID`, нажмите Enter.
2. В окне параметров задайте:
   - **Шаг сетки (м)** — расстояние между узлами сетки;
   - **Учесть направление** — если включено, после выбора границы укажите отрезок или полилинию, задающую ориентацию сетки;
   - **Имитировать неравномерный шаг** — включите, чтобы шаг изменялся случайно в заданных пределах (**Уменьшение, %** и **Увеличение, %**).
3. Нажмите **Выполнить**.
4. Выберите замкнутую полилинию-границу.

Плагин расставит отметки во всех узлах сетки внутри границы, где есть данные ЦМР, и выведет итоговый счётчик.
