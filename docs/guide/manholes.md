# Работа с колодцами

Инструменты для вставки и пересчёта отметок в атрибутах блоков канализационных колодцев.

---

## <img src="/icons/IGI_InsertKolodecAttrBlockText.svg" style="height:24px; vertical-align:middle"> IGI_InsertKolodecAttrBlockText — вставка значения в атрибут колодца

Вставляет новую отметку в последовательный атрибут **Z1–Z4** блока колодца (СП_4.1.2.1.л, СП_4.2.1 и др.), сдвигая остальные значения вправо. Подходит для точечного добавления отметки в заполненную цепочку.

1. Введите `IGI_InsertKolodecAttrBlockText`, нажмите Enter.
2. Выделите один блок колодца с атрибутами.
3. Укажите новую позицию (от 1 до доступного числа, например, 3).
4. Введите новое значение для этой позиции (например, отметку).
5. Плагин сдвинет существующие атрибуты и вставит новое значение на указанное место.

::: warning Внимание
Команда работает только с блоками, у которых атрибуты заполнены последовательно, без пропусков. Если в цепочке есть пустая ячейка посередине, команда сообщит об ошибке.
:::

## <img src="/icons/IGI_KolodecCalcZ.svg" style="height:24px; vertical-align:middle"> IGI_KolodecCalcZ — пересчёт высот в атрибутах колодцев

Вычисляет итоговые отметки Z1–Z4 как сумму базового Z и заданной дельты. Поддерживает формулы (`+`, `-`, `*`, `/`, скобки) и текстовые суффиксы.

1. Введите `igikolodeccalcz`, нажмите Enter.
2. Выделите один или несколько блоков колодцев с атрибутами.
3. Плагин для каждого блока:
   - считает базовое значение атрибута **Z**;
   - для каждого Z1–Z4 разберёт строку (например, `+0.5` или `-1.25`) и вычислит итог;
   - запишет результат, сохраняя текстовый суффикс (если был) и точность исходного числа.
4. В консоли появится лог каждого пересчёта.
