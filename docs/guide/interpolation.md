# Интерполяция горизонталей

Построение промежуточных горизонталей между блоками с высотными отметками.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_Interp — построение горизонталей между блоками СП_9.2

Строит промежуточные горизонтали с шагом 0,5 м между двумя или более блоками **СП_9.2**.

1. Введите `IGI_Interp`, нажмите Enter.
2. Выделите блоки **СП_9.2**:
   - **2 блока** — интерполяция выполнится сразу между ними.
   - **3+ блока** — выберите режим:
     - *Цепочка* — последовательно между блоками слева направо;
     - *Все* — между каждой парой блоков.
3. Плагин соединит блоки линиями, расставит круги в точках пересечения с полуметровыми уровнями и подпишет их высоты.
