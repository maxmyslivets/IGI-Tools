# Очистка и обслуживание

Инструменты для обслуживания плагина и очистки чертежа.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> CleanDynRotate — сброс динамического поворота блоков

Массово сбрасывает динамические свойства **«Угол» / «Угол1»** в блоках, устанавливая их на 90°, и переносит разницу в собственный поворот блока.

1. Введите `CleanDynRotate`, нажмите Enter.
2. Выделите блоки для обработки (можно выбрать тысячи блоков — команда оптимизирована для массовой обработки).
3. Плагин проверит каждый блок, выставит динамический угол в 90° и перенесёт разницу в поворот самого блока.
4. После обработки чертёж регенерируется однократно.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_RELOAD_ALL — перезагрузка всех команд

Перезапускает все команды IGI Tools без перезагрузки AutoCAD. Используется при обновлении скриптов или если команды перестали отвечать.

1. Введите `IGI_RELOAD_ALL`, нажмите Enter.
2. В консоли появится список перезагруженных модулей и сообщение об успешном завершении.
