# Выравнивание подписей

Инструменты для разворота подписей блоков вдоль линий.

---

## <img src="/icons/GEO_Tools.svg" style="height:24px; vertical-align:middle"> IGI_ALIGN_SP92 — выравнивание текста блоков вдоль опорной линии

Разворачивает подписи блоков **СП_9.2** и **СП_6.5.2** параллельно ближайшей линии, полилинии или дуге — текст читается вдоль дороги или границы.

1. Введите `IGI_ALIGN_SP92`, нажмите Enter.
2. Выделите рамкой линии/полилинии и блоки, которые нужно выровнять.
3. Каждый блок развернётся вдоль ближайшей кривой. Вертикальные тексты — «снизу вверх».
4. В командной строке появится отчёт: количество кривых, блоков и выровненных подписей.

::: tip Совет
Можно предварительно выделить нужные объекты — плагин подхватит их автоматически и не будет запрашивать выбор заново.
:::

::: info Информация
Блок, расположенный дальше 1 см от опорной линии, будет пропущен — об этом появится сообщение в консоли.
:::
