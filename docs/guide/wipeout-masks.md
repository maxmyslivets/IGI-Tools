# IGI_WipeoutCuff / IGI_WipeoutUncuff — видимость маскировок в блоках

Отключает (или восстанавливает) прорисовку объектов **Wipeout** (маскировок) внутри определений блоков. Маскировки внутри блоков значительно замедляют регенерацию и панорамирование в AutoCAD при работе с большими чертежами.

::: tip Назначение
**IGI_WipeoutCuff** — скрывает маскировки в блоках, повышая производительность отображения.
**IGI_WipeoutUncuff** — возвращает видимость маскировок, чтобы блоки имели структуру в соответствии с шаблоном СП.
:::

::: info Когда применять
- **При работе** с чертежом — используйте `IGI_WipeoutCuff` для комфортной навигации.
- **При сдаче** чертежа — используйте `IGI_WipeoutUncuff` для восстановления маскировок.
:::

---

## <img src="/icons/IGI_DisableMasks.svg" style="height:24px; vertical-align:middle"> IGI_WipeoutCuff — скрыть маскировки

1. Введите `IGI_WipeoutCuff`, нажмите Enter.
2. Все объекты Wipeout внутри блоков станут невидимыми, чертёж перестроится.

## <img src="/icons/IGI_RestoreMasks.svg" style="height:24px; vertical-align:middle"> IGI_WipeoutUncuff — восстановить маскировки

1. Введите `IGI_WipeoutUncuff`, нажмите Enter.
2. Видимость маскировок вернётся.
