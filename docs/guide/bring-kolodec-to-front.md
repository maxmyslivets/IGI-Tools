# IGI_BringKolodecBlocksToFront — порядок отображения блоков колодцев

Переносит блоки канализационных колодцев на передний план чертежа. Полезно, когда блоки колодцев перекрываются другими объектами (например, линии труб лежат поверх колодца) и их нужно сделать видимыми поверх всего.

::: tip Когда применять
- После прорисовки труб к центрам колодцев, когда они отображаются над колодцами.
- Обработка всего чертежа после разводки сетей.
- Перед выводом чертежа на печать — чтобы колодцы гарантированно отображались сверху.
:::

---

## <img src="/icons/IGI_BringKolodecBlocksToFront.svg" style="height:24px; vertical-align:middle"> IGI_BringKolodecBlocksToFront — вынести колодцы на передний план

1. Введите `IGI_BringKolodecBlocksToFront`, нажмите Enter.
2. Плагин автоматически найдёт все блоки канализационных колодцев (СП_4.1.2.x, СП_4.2.1, СП_4.3.1.1, СП_4.8.5.1 и их варианты с суффиксом `.л`) в чертеже.
3. Выбранные блоки будут перемещены на передний план с помощью команды `DRAWORDER`.
4. В консоли отобразится количество перемещённых блоков.
