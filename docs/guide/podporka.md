# Подпорки (сечения)

Расстановка блоков подпорок вдоль оси.

---

## <img src="/icons/IGI_Podporka.svg" style="height:24px; vertical-align:middle"> IGI_Podporka — расстановка подпорок вдоль оси

Размещает блоки **СП_3.59.2** (подпорки) вдоль выбранной оси с шагом 2 м, разворачивая их перпендикулярно оси и растягивая до пересечения с целевой линией.

1. Введите `IGI_Podporka`, нажмите Enter.
2. Выберите **первую полилинию (ось)**, вдоль которой размещать блоки подпорок.
3. Выберите **вторую полилинию (цель)**, до которой дотягивать блоки.
4. Плагин автоматически расставит блоки с шагом 2 м, рассчитав точное расстояние до пересечения с целевой линией.

::: info Информация
Для каждого блока рассчитывается точная дистанция через построение временного луча от оси до целевой линии. Если луч не нашёл пересечения, расстояние берётся как кратчайшее до целевой линии.
:::
