# IGI Tools

Плагин для **AutoCAD / Civil 3D** (2022–2027) с инструментами инженерно-геодезического оформления чертежей. Основан на [CADPyRx](https://github.com/CEXT-Dan/PyRx).

Установщик кладёт самодостаточный bundle (встроенный Python + CADPyRx) в `ApplicationPlugins` — плагин подхватывается автозагрузчиком Autodesk при старте CAD.

## 📦 Установка

**Требования:** Windows 10/11 x64, AutoCAD / Civil 3D 2022–2027 (не LT), права администратора.

1. Закройте AutoCAD.
2. Скачайте `IGITools-setup-{VERSION}.exe` из [Releases](https://github.com/maxmyslivets/IGI-Tools/releases).
3. Запустите от имени администратора, дождитесь копирования.
4. Запустите CAD — в командной строке появятся сообщения `[IGI Tools]`.

При наличии новой версии плагин предложит обновление и откроет скачивание в браузере. Подробнее — [документация по установке](https://maxmyslivets.github.io/IGI-Tools/guide/installation).

## 🛠️ Инструменты

Все команды сгруппированы по функциональным разделам:

### 📍 Точки и отметки
Преобразование объектов в высотные отметки, корректировка и выравнивание подписей.

| Команда | Назначение |
|---------|------------|
| z2sp92, z2sp652 | Создание отметок из 3D-полилиний, точек, текста |
| SP92ToPoints, SelectSP92 | Выбор и преобразование существующих отметок |
| BlockFan, BlockToVertex | Расстановка блоков вдоль полилинии / по вершинам |
| FIX_Z_SP92, FIX_Z_FROM_ATTR_SP92 | Корректировка высот отметок |
| Z0 | Обнуление абсолютных высот чертежа |
| AlignSP92 | Разворот блоков отметок вдоль линии |

### ✏️ Рисование
Автоматическая расстановка объектов и элементов оформления.

| Команда | Назначение |
|---------|------------|
| IGI_Podporka | Расстановка блоков СП_3.59.2 вдоль оси |
| IGI_FILL_AREA | Заливка области блоками и текстом внутри контура |

### ⛰️ ЦМР и рельеф
Построение горизонталей по высотным отметкам.

| Команда | Назначение |
|---------|------------|
| IGI_Interp | Интерполяция полуметровых горизонталей между отметками |

### 🤖 Автоматизация
Фоновые процессы.

| Команда | Назначение |
|---------|------------|
| DEM-трекер | Высота поверхности под курсором в реальном времени |
| Автоповорот отметок | Автоматический разворот блоков на слое дорожной сети |

### 🔌 Коммуникации
Инструменты для работы с блоками канализационных колодцев.

| Команда | Назначение |
|---------|------------|
| KolodecCalcZ | Расчёт отметок труб |
| InsertKolodecAttrBlockText | Вставка подписей колодцев |

### 🧩 Специальные инструменты
Импорт данных, построение буферов и сетки номенклатуры.

| Команда | Назначение |
|---------|------------|
| IGI_GZU_FROM_GEOJSON | Импорт границ землепользования из GeoJSON |
| IGI_BUFFER_POLY | Построение объединённых буферных зон |
| IGI_DRAW_NOMENCLATURE | Разграфка сетки номенклатуры 250×250 м |

### 🎨 Оформление чертежа
Настройка цветов слоёв, блоков и управление шаблоном.

| Команда | Назначение |
|---------|------------|
| SetLayerColors / ResetLayerColors | Управление цветами слоёв |
| SetManholeColors / ResetManholeColors | Управление цветами канализационных блоков |
| IGI_LOAD_TEMPLATE / IGI_RESET_TEMPLATE | Управление шаблоном DWG |

Полное описание каждой команды — в [документации](https://maxmyslivets.github.io/IGI-Tools/guide/core-tools).

## 🔧 Настройка шаблона

Некоторые команды используют блоки, слои и типы линий из `template.dwg`. В поставке — стандартный шаблон ВОИИ ГП «Геосервис». Если в организации свои блоки — замените шаблон один раз:

| Команда | Действие |
|---------|----------|
| `IGI_LOAD_TEMPLATE` | Выбрать свой DWG → копируется как `template.dwg` (старый → `template.dwg.bak`) |
| `IGI_RESET_TEMPLATE` | Вернуть заводской шаблон из `template.default.dwg` |

При переустановке установщик показывает опцию **«Обновить активный шаблон DWG»**: включена — замена, снята — `template.dwg` не трогается. `template.default.dwg` обновляется всегда.

## ✅ Проверка

| Что проверить | Команда |
|---------------|---------|
| CADPyRx загружен | `PYRXVER` или `PYRXLOADLOG` |
| Python-команда | например `IGI_DRAW_NOMENCLATURE` |
| LISP-команда | например `BlockFan`, `INTERP` |
| Шаблон DWG | `IGI_LOAD_TEMPLATE` / `IGI_RESET_TEMPLATE` |
| Интерфейс | вкладка `igi_tools.cuix` |

## ❓ Устранение проблем

- **Плагин не грузится** — bundle должен лежать в `Program Files\Autodesk\ApplicationPlugins` (не `ProgramData`).
- **Предупреждения о доверенных путях** — добавьте каталог bundle в `TRUSTEDPATHS`.
- **Нет Python-команд** — `PYRXLOADLOG`; проверьте `Contents\Python\pyrx_onload.py`.
- **Нет LISP** — проверьте `Contents\Lisp\` и сообщение загрузчика в командной строке.
- **Нет блока при импорте ГЗУ** — загрузите свой DWG через `IGI_LOAD_TEMPLATE`.

## 🗑️ Удаление

Через «Программы и компоненты» либо удалите папку:

`C:\Program Files\Autodesk\ApplicationPlugins\IGITools.bundle`
